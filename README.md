## 📖 About

This is my personal interactive CV and project portfolio, built entirely with **Python** and **Streamlit** — no external frontend framework required. It showcases my professional experience, technical skills, and academic projects in a visually engaging, single-page web application.

The project demonstrates frontend-style development using Python with embedded HTML/CSS through Streamlit's `components` API.

---

## ✨ Features

- 📄 **Downloadable CV** — one-click PDF download directly from the app
- 📧 **Email CV form** — send the resume to any email address
- 📊 **Animated skill bars** — visual proficiency indicators with smooth CSS transitions
- 🎴 **Auto-scrolling project cards** — Netflix-style infinite carousel of featured projects
- 💼 **Experience section** — hover-animated cards for each job role
- 🌍 **Languages & skills** — organized by technical, professional, and soft skills
- 🌙 **Dark mode support** — automatic styling adaptation for light and dark themes
- 🔗 **Social media links** — direct links to LinkedIn, GitHub, and Indeed

## 🚀 Getting Started

### Prerequisites

- Python 3.10 or newer
- pip

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/arathsam/Portafolio---ASMY.git
cd Portafolio---ASMY
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Run the app**
```bash
streamlit run App1.py
```

The app will open automatically at `http://localhost:8501`

### Requirements

```
streamlit
```

## 🚀 Deployment

This app is deployed on **Streamlit Community Cloud**:

1. Push code to GitHub
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect repository and set `App1.py` as the entry point
4. Deploy — no configuration needed
